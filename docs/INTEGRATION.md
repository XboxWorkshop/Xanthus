# Integration

## For Recomps

### Outline

To integrate Xanthus into your recompilation project using [XboxRecomp2](https://github.com/sewer56/XboxRecomp2), you'll have to follow a few key steps. This is the outline:
1. Give Xanthus access to your `x86` output folder via. CMake
2. Toggle `XANTHUS_RECOMP` via. CMake
3. Add our hash aliases for abstracted logic to your recomp configuration toml
